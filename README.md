# Papan Slot TravelMlg (dummy)

Prototipe klik untuk trial koordinasi jaringan travel antarkota Malang Raya: driver membuka slot kursi kosong, agen mencarikan kursi untuk penumpang, dan jam berangkat ke Bandara Juanda dihitung dari jadwal pesawat.

- `index.html` — app dummy (buka di HP untuk tampilan asli)
- `peta.html` — peta hubungan antar halaman

Semua nama, jam, dan slot adalah **data contoh**. Tidak ada server: data tersimpan di browser masing-masing pengguna dan bisa dikembalikan lewat menu Akun → Reset data contoh.

Angka hitung jam (tiba 2–3 jam sebelum terbang, perjalanan sekitar 2–3 jam) hanya nilai awal contoh dan bisa diubah di menu Akun.
